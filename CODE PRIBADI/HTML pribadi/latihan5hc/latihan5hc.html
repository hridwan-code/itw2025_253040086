About This Project

HRIDPLAY adalah sebuah project web game independen yang dikembangkan secara mandiri sebagai bagian dari portofolio pribadi. Project ini dibuat dengan tujuan mengeksplorasi pengembangan front-end, perancangan antarmuka (UI/UX), serta penerapan konsep visual bertema game retro yang dipadukan dengan pendekatan desain modern. Melalui project ini, penulis berfokus pada bagaimana sebuah website dapat menyajikan informasi game secara rapi, mudah diakses, dan nyaman digunakan. Mulai dari struktur layout, sistem pencarian, hingga detail interaksi kecil seperti animasi hover dan transisi, seluruh elemen dirancang untuk menciptakan pengalaman pengguna yang sederhana namun tetap menarik. Selain sebagai media eksplorasi desain, HRIDPLAY juga berfungsi sebagai sarana pembelajaran dalam membangun website yang terstruktur, responsif, dan konsisten secara visual. Project ini mencerminkan proses belajar berkelanjutan dalam bidang pengembangan web, khususnya pada sisi front-end, sekaligus menjadi representasi kemampuan teknis dan pendekatan desain yang diterapkan dalam satu platform terpadu.
